# GRPH-008 Phase 1 — Declared Type Facts

Phase 1 adds an optional, source-only declared-type payload to TypeScript, TSX, and JavaScript AST parse results. The existing `ScopeResolver`, call-site fields, graph persistence, and materialized `calls` edges remain unchanged. Facts are explicit syntax with source spans and owner/scope provenance; they do not claim name resolution or type-checker certainty.

## Grammar and provenance coverage

The extractor recognizes simple named types at fields, parameters, TypeScript constructor parameter properties, variable annotations, direct `new C()` initializers, callable return annotations, and class/interface `implements` and `extends` clauses. JavaScript contributes direct `new C()` initializers and simple class inheritance; JSDoc annotations are not treated as facts. Every fact carries declaration and type spans, its owner, and a lexical scope span. Callable/member inventories are separate from typed facts, so untyped JavaScript callables and incomplete/computed members remain visible.

Positive fixtures run against the checked-in TypeScript, TSX, and JavaScript tree-sitter WASM grammars. Negative fixtures verify abstention for generic shadowing/application, unions and intersections, mapped, conditional, indexed-access, callable and object types, generic or computed inheritance, mixins, JSDoc-only hints, and malformed syntax. Regression fixtures also cover comments among formal parameters, single-parameter arrows, callable-valued class/object members, and function-scoped `var` metadata. The focused worker and grammar suite passes **15/15** tests; `pnpm run typecheck` passes.
