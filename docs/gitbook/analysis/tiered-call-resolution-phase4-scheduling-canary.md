## Behavior

- Queue priority is ambiguous/unresolved and unsupported first, likely second, proven third. Signature and file ordering are stable within a priority. A proven result alone never grants skip permission.
- Q1 named-import certification is active only when the packaged artifact matches its pinned SHA-256 and provenance, both certification tracks validate, and the current Q1 rule-configuration pin matches. Canary eligibility also requires a current portable identity, matching source hash, and proven selected target. The sampler hashes the policy version, call-site key, and rule signature; a changed resolution class cannot move a site into another sample. The rate is validated in `[0, 1]`, defaults to `0.1`, and is recorded with the policy version and per-signature selected/overridden keys.
- Local quarantine overrides Q1 certification and sends affected sites to Tier B with an effective ambiguous class. Clearing a quarantine is explicit and audited; the clear path accepts only trusted newer certification or an operator record, and both require a changed rule-configuration hash. A later valid contradiction can quarantine the signature again.
- LSP outcomes remain separate from the source resolution class. A unique local target updates the selected target and rebuilds only the affected caller-file projection in one SQLite transaction. A collapsed old edge stays while another current site selects it, then disappears after the last site moves.
- Only a normal unique-local response that differs from a non-null proven target quarantines a signature. Other outcomes remain observations and do not alter the selected target or quarantine state. Quarantine is local runtime state; affected unverified sites are sent as Tier B with an effective ambiguous class while their source class and prior evidence remain intact.

The Q1 report is certification evidence, and runtime trust is granted only by the separately pinned product resource. Each Tier B batch records `analyze.tierB.call_resolution_certification` in `.docuvia/logs/analyze.log` with `certificationStatus` (`trusted`, `rejected`, or `missing`), the artifact digest, certified signatures, and rejection reasons. A missing or rejected decision sends every site through Tier B. Quarantined signatures also remain on Tier B until the audited clear path is used.
