## Behavior

- Queue priority is ambiguous/unresolved and unsupported first, likely second, proven third. Signature and file ordering are stable within a priority. A proven result alone never grants skip permission.
- Canary eligibility requires a current portable identity, matching source hash, proven selected target, and a trusted certification artifact. The sampler hashes the policy version, call-site key, and rule signature; a changed resolution class cannot move a site into another sample. The rate is validated in `[0, 1]`, defaults to `0.1`, and is recorded with the policy version and per-signature selected/overridden keys.
- LSP outcomes remain separate from the source resolution class. A unique local target updates the selected target and rebuilds only the affected caller-file projection in one SQLite transaction. A collapsed old edge stays while another current site selects it, then disappears after the last site moves.
- Only a normal unique-local response that differs from a non-null proven target quarantines a signature. Other outcomes remain observations and do not alter the selected target or quarantine state. Quarantine is local runtime state; affected unverified sites are sent as Tier B with an effective ambiguous class while their source class and prior evidence remain intact.
