# Verification Report: 4.4.1 — Nullable documents.projectId

**Item ID:** 4.4.1

**Date:** 2026-06-11
**Revision:** HEAD
**Verdict:** ✅ PASS

## Design Spec References
- ADR-012 (Document Misc Pool) requires that `documents.projectId` can be null, indicating a document belongs to the global "Misc Pool" rather than a specific project.

## Implementation Details
- `lib/db/src/schema/documents.ts` defines `projectId: integer("project_id").references(() => projectsTable.id, { onDelete: "cascade" })` which is nullable by default in Drizzle ORM.
- `artifacts/api-server/src/routes/documents.ts` uses `isNull(documentsTable.projectId)` to query for Misc Pool documents.

This item is fully implemented and functioning correctly.
