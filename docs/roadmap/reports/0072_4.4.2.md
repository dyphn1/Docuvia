**Item ID:** 4.4.2

**Date:** 2026-06-11
**Revision:** HEAD
**Verdict:** ✅ PASS

## Design Spec References
- ADR-012 specifies that documents must be hashed using SHA-256 upon upload to prevent duplicate ingestion into the Misc Pool or projects.

## Implementation Details
- `lib/db/src/schema/documents.ts` contains `contentHash: text("content_hash")`.
- `artifacts/api-server/src/lib/ingestion-pipeline.ts` explicitly checks for existing hashes `eq(documentsTable.contentHash, hash)` before inserting a new document, preventing duplicates.

This item is fully implemented.
