# Verification Report: 4.4.3 — Misc pool extraction without L1/L2/L3 generation

**Item ID:** 4.4.3
**Description:** Misc pool extraction without L1/L2/L3 generation
**Date:** 2026-06-13
**Verdict:** ⚠️ WARN

## Team Review (Architecture & SRE)
- **Leo (Architect)**: Documents lacking a `projectId` should be extracted to the pool without triggering expensive Knowledge Graph generation pipelines.
- **Max (SRE / Security)**: Wait, what prevents an attacker from spamming the Misc Pool with anonymous documents and filling the disk? And if generation is bypassed, is the background worker still trying to pick it up? Enforce a strict file count quota for the anonymous pool, and set `status = 'pending_affiliation'` explicitly so workers ignore it.
- **Conclusion**: Security mandated change (Misc Pool Quotas & Status Flags).
