## Team Review (Architecture & SRE)
- **Leo (Architect)**: Users can associate a Misc Pool document to a project via `POST /documents/:id/affiliate`, which then triggers the generation pipeline.
- **Max (SRE / Security)**: Who is authorized to do this? If there is no project isolation on the Misc Pool, User A can associate User B's private uploaded document to their own project. The Misc Pool must have an `uploadedBy` owner ID, and affiliation requires strict authorization checks.
- **Conclusion**: Security mandated change (Misc Pool Authorization).
