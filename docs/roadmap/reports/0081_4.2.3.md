## Design Spec References
- ADR-010 requires a confirmation UI for AI-discovered L2 modules.
- `completion_action_plan.md` dictates a specialized view grouping modules by L1 Tags, indicating New vs Existing, and providing bulk actions.

## Implementation Details
- `artifacts/kg-engine/src/components/L2BootstrapReview.tsx` implements the review component.
- The UI groups modules, shows Diff Views (New/Existing), and sends the approved/rejected IDs and paths to the `confirm-bootstrap` API.
