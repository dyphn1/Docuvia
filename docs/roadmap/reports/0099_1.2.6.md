# Verification Report: 1.2.6 — Incremental ingestion via cursor columns

**Item ID:** 1.2.6
**Description:** Incremental ingestion via cursor columns (lastGitIngestedAt, lastSvnRevision, processedAt)
**Date:** 2026-06-12
**Verdict:** ⚠️ WARN

## Implementation Details & Architecture Debate
- **Debate Issue**: Attempting to ingest the full history in a single pass is unstable.
- **Resolution**: The system must enforce incremental ingestion strictly using cursor columns (`lastGitIngestedAt`, `lastSvnRevision`). Batches must be limited to 50 commits at a time to prevent CPU/memory spikes.
