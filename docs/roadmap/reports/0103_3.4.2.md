## Team Review (Architecture & SRE)
- **Leo (Architect)**: The design implied clients might auto-merge and push to the orphan branch directly.
- **Max (SRE / Security)**: We established in 3.4.1 that writes MUST be centralized. Clients fetching and resolving CRDTs over Git is a distributed nightmare. Clients push via REST, Server holds the lock, writes to DB, and handles Git.
- **Conclusion**: Architecture mandated fix (Centralized Server REST sync).
