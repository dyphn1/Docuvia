## Team Review (Architecture & SRE)
- **Leo (Architect)**: Will use `crypto.createHash` on `req.file.buffer`.
- **Max (SRE / Security)**: Loading a 2GB file into V8 heap buffer will cause OOM. Use `multer` disk storage and compute the hash via streaming (`createReadStream().pipe(hash)`).
- **Conclusion**: Security mandated change (Stream hashing to prevent OOM).
