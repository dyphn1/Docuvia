# Verification Report: 10.3.2 — Extension activation events configured

**Item ID:** 10.3.2
**Description:** Extension activation events configured
**Date:** 2026-06-13
**Verdict:** ✅ PASS

## Team Review (Architecture & SRE)
- **Max (SRE / Security)**: IDE extensions that use the `*` (on startup) activation event are parasitic. They drag down the user's editor boot time and get uninstalled within an hour.
- **Leo (Architect)**: We will completely ban the `*` activation event. We will configure `package.json` to use granular, lazy-loaded activation events: `onCommand`, `onView`, or `workspaceContains:AGENTS.md`.
- **Conclusion**: Performance mandated change (Strict lazy-loading).
