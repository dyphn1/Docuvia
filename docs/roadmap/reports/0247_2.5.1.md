**extension.ts implementation** (`artifacts/vscode-client/src/extension.ts:223-232`):

```typescript
// Check KB size limit
const maxKB = config.get<number>("extraction.maxFileSizeKBWarning", 50);
const fileSizeKB = Buffer.byteLength(editor.document.getText(), "utf-8") / 1024;
if (fileSizeKB > maxKB) {
  const proceed = await vscode.window.showWarningMessage(
    `Docuvia: This file is large (${fileSizeKB.toFixed(1)} KB). Extraction might be slow. Proceed anyway?`,
    "Proceed",
    "Cancel"
  );
  if (proceed !== "Proceed") return;
}
```

**Implementation analysis:**

- ✅ Reads config with `config.get<number>('extraction.maxFileSizeKBWarning', 50)` — correct key, correct default
- ✅ Computes file size using `Buffer.byteLength(..., 'utf-8') / 1024` — accurate UTF-8 byte size in KB
- ✅ Shows `vscode.window.showWarningMessage` with file size formatted to 1 decimal place
- ✅ Offers 'Proceed' / 'Cancel' options — consistent with line count warning pattern
- ✅ Returns early if user does not proceed — correctly aborts extraction
- ✅ Gate ordering is correct: include patterns → line count → KB size → dispatch (matches design spec)
