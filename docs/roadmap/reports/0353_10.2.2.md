### Round 3: Correctness — Are the documented vars correct?

Verified documented variables against actual implementation:

1. **`PORT`** — ✅ Correct. Server throws on startup if missing (confirmed in AGENTS.md "System Boundaries").
2. **`DATABASE_URL`** — ✅ Correct. Used by `lib/db/src/index.ts:18-22` with explicit null check.
3. **`OPENAI_API_KEY`** — ⚠️ **Partially correct.** The deployment docs list it as a direct env var, but the actual code uses `AI_INTEGRATIONS_OPENAI_API_KEY` and `AI_INTEGRATIONS_OPENAI_BASE_URL` via the `integrations-openai-ai-server` package. The `OPENAI_API_KEY` name is referenced only as a conventional name in the LLM config system — operators setting it directly would have no effect unless they also configure the integration layer.
4. **`GITHUB_WEBHOOK_SECRET`** — ✅ Correct. Used in `github_webhooks.ts:131-136` for HMAC validation.
5. **`NODE_ENV`** — ✅ Correct. Used in `logger.ts` and `metabolism.ts`.
6. **Slack/Teams URLs note** — ✅ Correct. These are stored in `project_integrations` table, not env vars.

## Verdict

**WARN** — The environment variables documentation covers only 5 of 16 runtime env vars (31%). Two **critical** required variables (`AI_INTEGRATIONS_OPENAI_BASE_URL`, `AI_INTEGRATIONS_OPENAI_API_KEY`) and one **critical** auth variable (`MCP_PAT`) are completely undocumented — operators setting up the system will encounter startup failures. Additionally, the documented `OPENAI_API_KEY` name doesn't match the actual variable name used in code, which will cause confusion during initial configuration.

The documentation structure is correct (table format, required/conditional classification, defaults), but the content is severely incomplete. The docs were clearly written early in development and were not updated as new env vars were added.

## Recommended Actions

1. **[CRITICAL] Add missing required vars to `07-deployment.md` §7.2:**
   - `AI_INTEGRATIONS_OPENAI_BASE_URL` — Required, no default
   - `AI_INTEGRATIONS_OPENAI_API_KEY` — Required, no default
   - `MCP_PAT` — Required, no default

2. **[HIGH] Add missing conditional/optional vars:**
   - `ADMIN_SECRET_TOKEN` — Required in production
   - `GITHUB_TOKEN` — Conditional (PR integration)
   - `DOCUVIA_API_URL` — Conditional (CLI tool)
   - `LOG_LEVEL` — Optional (default: `info`)

3. **[MEDIUM] Fix `OPENAI_API_KEY` naming:** Either rename to match `AI_INTEGRATIONS_OPENAI_API_KEY`, or document both names with a note that the integration layer uses prefixed variables.

4. **[LOW] Add dev/test vars for completeness:**
   - `DOCUVIA_MOCK_SERVER` — Test mode for VS Code client
   - `BASE_PATH` — Frontend base path
   - `API_BASE_URL` — Frontend API proxy target
