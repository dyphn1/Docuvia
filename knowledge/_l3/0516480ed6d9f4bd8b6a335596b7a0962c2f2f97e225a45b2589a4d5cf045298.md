The Tier B Commit Cap Check now runs even when only skipGit is set (it previously needed IGitProvider). The store's meta counter for changed-bytes is read directly from GraphStoreOpener; no git provider is consulted. The check is still gated by skipDb, the GraphStoreOpener registration, and a successful store open.
