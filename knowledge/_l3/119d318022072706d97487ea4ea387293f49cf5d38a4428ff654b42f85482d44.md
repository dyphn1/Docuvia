The snapshotCommitMessage function constructs a commit message that includes a trailer using GitConstants.SOURCE_COMMIT_TRAILER_KEY ('Docuvia-Source') followed by the full source commit SHA. This embeds domain-specific provenance metadata directly into git commit messages, enabling Phase 2's nearest-ancestor hydration lookup to trace knowledge-branch snapshots back to their originating source commits.
