GitMessages.snapshotCommitMessage references GitConstants.SOURCE_COMMIT_TRAILER_KEY rather than duplicating the string literal. This enforces a single source of truth for the trailer key value, ensuring that if the key changes in GitConstants, the commit message format automatically stays in sync without requiring updates in both places.
