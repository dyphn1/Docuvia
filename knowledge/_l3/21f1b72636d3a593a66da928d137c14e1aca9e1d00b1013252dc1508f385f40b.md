The private runOrSkip method abstracts the skip/run decision logic. When called with skip=true, it immediately returns true (skipping the check). Otherwise, it executes the provided run function and converts the result to a boolean (treating undefined as true). This ensures each of the ~12 diagnostic checks is a single, self-contained operation without nested branching, keeping the execute() method's cyclomatic complexity low.
