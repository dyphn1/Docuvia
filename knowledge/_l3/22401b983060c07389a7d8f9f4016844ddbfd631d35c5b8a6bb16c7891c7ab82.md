persistLocked captures incoming node_links into the batch nodes whose source file is outside the batch (IGraphNodesRepo.getExternalIncomingLinks: node_key index range <path> / [<path>#, <path>$) plus node_links target index, contains excluded, deduplicated) before the per-file replace, and after the insert and linking passes re-inserts each one whose node_key still resolves via findNodeIdByNodeKey, in the same transaction. Edges into removed or renamed symbols are dropped. deleteNodesForPath deletes incoming links too, so no dangling rows remain; pruneOrphanedLinks is legacy hygiene only. Rationale: without an LSP, Tier B never repaired non-contract re-parses, so unchanged dependents were lost permanently and impact could read exact with missing dependents.
