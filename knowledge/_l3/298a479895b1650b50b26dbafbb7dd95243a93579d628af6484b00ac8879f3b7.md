The Agent-Authored Adoption Check is always informational. It compares Git HEAD against the graph's last-ingested source SHA, gathers recently changed files via GitProvider.getChangedFilesSince, counts L3 rows with source = L3DecisionSources.AGENT_AUTHORED via store.l3.getAllExportable, and reads pending-l3-decisions.json for staged decisions. The diagnostic message reports flushed/staged/unchanged counts but never returns FAIL or alters allPassed.
