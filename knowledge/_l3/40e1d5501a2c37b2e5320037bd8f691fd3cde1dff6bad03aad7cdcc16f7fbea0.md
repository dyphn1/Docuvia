The Worktree Divergence Check uses GitProvider.listWorktrees and, for each sibling worktree path, stats <sibling>/.docuvia/local.db. If exactly one worktree exists the check reports PASS. If siblings exist but none carry a local.db the check reports PASS (shared graph). If any sibling carries its own local.db the check FAILs, includes the sibling path(s) in the message, and surfaces DOCTOR_MESSAGES.WORKTREE_DIVERGENCE_SUGGESTION.
