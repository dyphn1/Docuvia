GitMessages includes factory functions for generating markdown content (markdownFrontmatter, markdownFileBody, markdownSymbolBody) that handle optional filePath fields using conditional template expressions. This allows the same message generation logic to produce valid markdown frontmatter and body content for both file and symbol nodes, with graceful handling of missing file paths.
