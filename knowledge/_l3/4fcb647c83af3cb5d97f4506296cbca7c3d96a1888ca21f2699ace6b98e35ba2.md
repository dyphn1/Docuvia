IMPT-001 keeps a symbol target's containing-file 'contains' row in the reported blast radius and in the computeRiskLevel count. ImpactWorkflow.countRealDependents() excludes that row (a static entry named exactly the symbol node's filePath; file targets never list themselves) only when deciding whether the confirmed set is empty for resolveImpactEpistemic. Otherwise a symbol with no real dependent at full coverage was reported exact MEDIUM, a verified zero-impact claim. The reported radius and risk band of symbols with real dependents are unchanged.
