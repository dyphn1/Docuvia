File discovery now hashes the source bytes read from disk or Git as SHA-256. Git blob IDs remain lookup keys and are not reused as AST source hashes, allowing complete full-ingestion call-site proofs to pass their existing source-hash precondition. Strict proof boundaries, projection policy, and delta conservatism remain unchanged.
