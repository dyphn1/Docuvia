When fix:true, the Git Hook Check now dispatches to KnowledgeGitService.installPostCommitHook for stale tiers (legacy-only, or current-shaped but predating the commit-l3-write flush step from issue #48) in addition to the prior duplicate-block case handled by repairDuplicatePostCommitHook. The Pre-Push Hook Check similarly dispatches to installPrePushHook for pre-sync-knowledge / pre-hooks-check / pre---fallback-ast env-gate stale tiers. Resolvability-only failures are not repaired. A 'Repaired' note is appended to the diagnostic message when a repair is performed.
