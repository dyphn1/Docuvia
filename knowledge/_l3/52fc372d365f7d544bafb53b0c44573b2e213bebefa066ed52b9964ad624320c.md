The P2-B System One evaluator uses source-only candidate ranking and a calibration-selected score threshold to emit evaluation-only likely/ambiguous measurements even when candidateSetComplete is false. This empirical selection must not be treated as proven resolution, populate production certification, change call-edge projection, or authorize Tier B skipping. Calibration labels alone select the threshold; test and temporal labels are opened only after the freeze for fixed regression reporting.
