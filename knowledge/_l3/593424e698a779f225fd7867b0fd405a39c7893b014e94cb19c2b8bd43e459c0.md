The Canary Self-Test pulls a canary sample from the graph store and, for each sampled name, asserts that graph.findNodeByName resolves it. It also runs an FTS probe via fts.searchL2Nodes on the first sampled name that contains a >=3-character alphanumeric segment, and expects that probe to return at least one result. Names lacking an alphanumeric segment of that length cause the FTS probe to be skipped rather than failed. A missing canary sample (empty array) suppresses the check silently because graph_empty owns that verdict.
