GitMessages is declared with `as const`, making it a deeply-frozen object literal. It centralizes human-readable log messages and report text used across the `git/` domain services, ensuring immutability and a single source of truth for user-facing strings. This prevents accidental mutation and allows consumers to reference stable message keys rather than scattering string literals.
