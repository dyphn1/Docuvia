META_KEY_LAST_INGESTED_SOURCE_SHA records the source commit SHA the graph was last ingested from, while META_KEY_KNOWLEDGE_TIP_SHA tracks the last git hydration tip; this separation enables idempotency fast‑path checks and delta baseline comparison.
