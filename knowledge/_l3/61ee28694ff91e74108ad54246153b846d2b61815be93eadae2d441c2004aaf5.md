Diagnostic messages follow a consistent pattern of pairing status messages with suggestion messages (e.g., TIER_B_CAP_OK/TIER_B_CAP_EXCEEDED, GIT_HOOK_NOT_INSTALLED with various error states). This enables the UI to present both the problem and the remediation path.
