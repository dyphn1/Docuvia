The Graph Empty Check fails when a project row exists but the L2 node count is 0, or when no project row exists at all. The FAIL message is sourced from DOCTOR_MESSAGES.GRAPH_EMPTY_SUGGESTION (telling the user to run `docuvia init`). An empty graph does not cascade into the L2 semantic coverage check: totalNodes==0 is treated as full coverage (PASS) because graph_empty owns the empty-graph verdict.
