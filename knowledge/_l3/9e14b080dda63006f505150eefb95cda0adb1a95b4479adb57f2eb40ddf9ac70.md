GitMessages mixes plain string constants (e.g., DETECTED_CHANGES, KNOWLEDGE_BRANCH_ALREADY_EXISTS) with parameterized factory functions (e.g., analysisBase, snapshotCommitMessage, hydrateRefusedCatastrophicShrink). The factory functions use template literals to interpolate dynamic values like base commit SHAs, file counts, and node counts, enabling consistent message formatting while keeping the message structure centralized.
