When L2 semantic coverage is below the threshold (e.g. 0/6285) AND Tier C is not configured (no llmBaseUrl supplied), the diagnostic is reported as PASS with an explanatory message rather than FAIL. Descriptions cannot be written without an LLM bridge, so a structural-only graph is treated as a legitimate state, never a permanent red.
