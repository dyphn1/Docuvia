Symbol node keys (used for uniqueness in `l2_nodes`) are constructed as `${file}#${name}` but disambiguated on collision using the symbol's start line (or a counter if lines repeat). This preserves readable keys (e.g., `file#function`) for the common case while guaranteeing uniqueness for edge cases like chained callbacks on the same line or overloaded functions.
