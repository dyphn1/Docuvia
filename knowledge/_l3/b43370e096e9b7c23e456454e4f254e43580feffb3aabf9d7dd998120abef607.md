`resolveTargetNodeId` and `resolveSourceNodeId` implement fallback chains for edge resolution: target symbols fall back to file nodes if the symbol is untracked (e.g., re-exports), while source symbols fall back to file nodes for module-level call sites. This ensures edges are always created between valid nodes, even when symbol-level resolution fails.
