The commit introduces a forward resolution path in BaseLspEdgeProvider that, for each AST-seeded call site, resolves the callee using the LSP textDocument/definition request (module-level resolution) rather than a project-wide reverse scan, reusing the existing openFileCache/node_key caching from the reverse path, and selects the first in-workspace definition result for multi-location responses while discarding empty, out-of-workspace, or same-file targets.
