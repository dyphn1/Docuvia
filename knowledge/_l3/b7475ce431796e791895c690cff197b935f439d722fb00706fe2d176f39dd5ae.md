Anonymous symbols (e.g., callbacks) are explicitly handled by comparing `sourceSymbolName` to `ANONYMOUS_SYMBOL_NAME` in `resolveSourceNodeId`. If matched, the source node defaults to the file node, avoiding attempts to resolve non-existent symbol names.
