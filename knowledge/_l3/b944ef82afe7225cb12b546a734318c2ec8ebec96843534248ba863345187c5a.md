The call-site resolution repository owns the SQLite materialization of `node_links(calls)`. Replacing a caller file rebuilds its collapsed call edges inside the same transaction from all current non-stale per-site selected targets, deduplicating shared caller-to-target pairs. It clears only calls edges sourced by nodes whose project and path_patterns identify that caller file, preserving other relationship types and other callers. Dependency invalidation rebuilds each affected caller file projection in the transaction that marks observations stale. Per-site resolution rows remain authoritative; node_links is derived state.
