The Pre-Push Hook Check uses a hookName-aware readHookFile mock contract: assertions return a value only for GitConstants.PRE_PUSH_HOOK_NAME and undefined for the post-commit hook. This is required because the legacy/current marker strings for pre-push and post-commit overlap textually ('docuvia analyze'), and a shared mock return value would falsely trip the post-commit duplicate-block check too.
