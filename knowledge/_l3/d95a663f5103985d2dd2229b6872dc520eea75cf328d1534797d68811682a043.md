Worker spawns (`new Worker(<path>)`) are resolved by relative file path via `ScopeResolver.resolveWorkerSpawnPath`, not symbol imports. The target is always a file node (not a symbol), and the edge type is `DEPENDS_ON`. This mirrors the runtime behavior where worker scripts are standalone files, not imported bindings.
