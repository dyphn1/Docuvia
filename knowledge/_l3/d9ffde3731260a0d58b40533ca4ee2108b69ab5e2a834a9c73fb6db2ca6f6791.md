The DiagnosticResult object includes status (DiagnosticStatus enum), message (string), and suggestion (optional string). This structure allows the system to provide contextual feedback (messages) and actionable guidance (suggestions) for each failed check, enabling the UI to display meaningful diagnostics rather than generic failures.
