The `linkSymbolReference` method resolves `implements`/`extends` edges using a two-phase approach: first, `ScopeResolver.resolveCall()` checks same-file locals and explicit imports (JS/TS model); if unresolved, it falls back to a project-wide name lookup (`findNodeByName`). This accommodates languages like C#/Java/Go, where base classes/interfaces are often visible without imports. The fallback is disabled for `calls` to avoid false matches on common method names.
