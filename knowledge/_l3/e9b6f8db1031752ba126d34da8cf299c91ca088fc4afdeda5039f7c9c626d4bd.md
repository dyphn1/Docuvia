Strict call-resolution rules and hypothesis selection consult a workspace-wide candidate inventory, while persisted proof dependencies cover only caller and target paths and abstentions may have no dependency rows. Delta ingestion therefore invalidates all current resolutions and reparses every tracked source file after a source delta. This conservative fallback also refreshes legacy proof rows without schema metadata. The cost is proportional to workspace source-file count and is logged in the delta summary; invalidation occurs inside the knowledge lock so intermediate graph state is not observable.
