The `hydrate()` method enforces two refusal conditions to prevent data loss: (1) it refuses to proceed if `META_KEY_KNOWLEDGE_PACK_PENDING` is set (indicating a pending local write), and (2) it refuses if the incoming graph's node count is catastrophically smaller than the current store's count (ratio-based shrink guard). Both conditions are bypassed only when `options.force: true` is explicitly provided.
