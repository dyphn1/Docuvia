The `resolveHydrationCommit()` method resolves the knowledge commit by: (1) returning `undefined` if the knowledge branch doesn’t exist, (2) falling back to the branch tip if no commit has a `Docuvia-Source` trailer, (3) selecting the commit whose trailer SHA is the nearest ancestor of the source HEAD, and (4) preferring the newest commit if a source SHA was analyzed multiple times (rollback re-analysis).
