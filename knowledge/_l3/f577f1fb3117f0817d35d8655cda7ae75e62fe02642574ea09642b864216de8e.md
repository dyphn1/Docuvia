The function is explicitly shared by `GraphPersisterService`'s per-run rollup, the orchestration layer's meta stamping, and `doctor`'s `call_graph_resolution` diagnostic. The architectural rule is that a single canonical aggregation source prevents these consumers from drifting apart, while still keeping raw counters individually stamped in meta so any consumer can re-derive older/wider denominators.
