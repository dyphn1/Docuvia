When the graph's last-ingested source SHA differs from HEAD, the check reads <docuvia>/logs/analyze.log and inspects the most recent analyze.delta.summary timestamp. If the timestamp is within a grace window the check reports PASS with a 'recently active' note (an in-flight post-commit run). If analyze.log is missing, or the newest event is older than the grace window, the check FAILs and surfaces a suggestion to run `docuvia analyze`. An unborn/headless HEAD (no commit to compare against) suppresses the check silently.
