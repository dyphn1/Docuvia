compileQuery() returns undefined both when a language declares no such query and when a declared pattern fails to compile against the grammar, and extractNodes() silently falls back to descendantsOfType in either case. That made a real grammar-compat break indistinguishable from 'nothing to index here' -- it surfaced only as quietly missing symbols/edges downstream. Declared-but-failed patterns are now recorded on the provider and drained by ast-worker into the IPC logger (AstMessages.QUERY_COMPILE_FAILED); an undeclared query stays silent, since most languages legitimately omit optional queries. Corollary rule: a language's descendantsOfType fallback list MUST cover the same node types as its query. TS/JS `imports` gained `(export_statement source: (string))` in the query without gaining export_statement in the fallback list, so a compile failure degraded re-export descriptors to exactly an empty array rather than an error.
