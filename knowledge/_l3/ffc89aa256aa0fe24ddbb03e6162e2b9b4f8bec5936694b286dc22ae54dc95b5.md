The test mock for `store.graph.findNodeIdByName` returns `undefined` for all inputs except a specific file ('prevBatch.ts'), forcing the implementation to fall back to a database lookup when a symbol reference cannot be resolved from the in-memory fileIdMap (e.g., for cross-batch references). This ensures cross-file symbol resolution works even when the target file was processed in a previous batch.
